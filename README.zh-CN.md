## 痛点

> 人人都在问：「AI 会取代我吗？」—— 但没人能给出一个基于数据的真实答案。

现有的评估要么是性格测试，要么是自评问卷，没有一个工具真正去**看你怎么用 AI**，来判断**你在 AI 时代的真实位置**。

## 解决方案

**DAMC** 是一个 Claude Code 技能，**用 AI 来评估你和 AI 的关系**。它自动扫描你的 AI 使用环境（skills、配置、记忆系统、自动化管道、git 历史），结合简短的职业画像，生成量化的、可执行的评估报告。

没有问卷。没有自评偏差。只有数据。

## 快速开始

```bash
# 安装
npx skills add https://github.com/anthropics/damc-skill

# 运行
# 在 Claude Code 中输入:
/damc
```

## DAMC 框架

| 维度 | 全称 | 核心问题 | 权重 |
|------|------|---------|------|
| **D** | 蒸馏价值 | 你的经验值得被蒸馏成 AI Skill 吗？ | 25% |
| **A** | 抗蒸馏指数 | 你的哪些能力是 AI 拿不走的？ | **30%** |
| **M** | AI 驾驭力 | 你驾驭 AI 工具的水平如何？ | 25% |
| **C** | 职业适配 | 基于以上三维，你该往哪走？ | 20% |

### 8 大画像

| 画像 | D | A | M | 描述 |
|------|---|---|---|------|
| 🏆 AI 架构师 | 高 | 高 | 高 | 有料、不可替代、还会用 AI |
| 🎯 待觉醒专家 | 高 | 高 | 低 | 钻石级经验，还没用 AI 放大 |
| ⚡ 效率怪兽 | 高 | 低 | 高 | 高效执行者，但工作容易被纯 AI 替代 |
| 🚨 危险区 | 高 | 低 | 低 | 知识可蒸馏 + 无AI能力 = 需立刻行动 |
| 🌟 AI 原生创造者 | 低 | 高 | 高 | 创造力 + AI = 如虎添翼 |
| 💎 未雕琢的钻石 | 低 | 高 | 低 | 有独特价值，还没发现 AI 的放大效应 |
| 🔧 AI 工具人 | 低 | 低 | 高 | 会用 AI ≠ 有价值 |
| 📚 探索者 | 低 | 低 | 低 | 最好的重新定位时机 |

## 隐私设计

```
✅ 永远留在本地：CLAUDE.md 内容、memory 内容、git 原文、skill 名称、项目路径
🔒 仅上传（需明确同意）：数字分数 + 画像名（零原始内容）
```

## 技术架构

- **自包含 HTML 报告**：单文件、零依赖、离线可用，暗色主题 + SVG 雷达图 + 动画
- **混合评分模型**：M 维度 100% 客观扫描，D/A 混合自动信号 + 角色推断
- **Claude Code 原生**：无需后端、浏览器插件或额外配置
